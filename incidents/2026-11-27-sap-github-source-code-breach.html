重要 情報漏えい・侵害 2026年11月27日 ・ 海外

独SAP、GitHub上の不審活動でインシデント確認 ソースコード改変の報道

独SAPは、自社のIT環境とGitHub上で不審な活動を検知したとして、セキュリティインシデントを認めた。報道によれば、攻撃者は窃取した従業員のアクセストークンを使ってソースコードを複製・改変したとされ、同社は顧客保護のため緊急の対応を取ったという。

原因・侵入経路

報じられている原因は、従業員のアクセストークン（システムにログインするための認証情報）の窃取と、GitHub上の開発リポジトリへの不正アクセスである。SAPは不審な活動の検知後に該当アクセスを遮断し、顧客向けの保護措置を講じたと説明しているが、侵入経路の詳細や改変されたコードの範囲は明らかにしていない。開発基盤そのものが狙われた点で、自社製品のサプライチェーン（供給網）への影響が焦点となる。

影響・被害規模

SAPのERP「S/4HANA」などは日本企業を含む世界中の基幹業務で使われており、影響は顧客企業の業務システムに波及し得る。現時点で顧客データの漏えいや製品への不正コード混入が起きたかどうかは明らかにされておらず、被害件数も不明。同社は詳細の調査を続けているとみられる。

AI との関係

AIの関与は確認されていない。ただしソースコードを扱う開発基盤が狙われた事例として、ビルド成果物の来歴（provenance）を署名で検証し、人の目視に頼らず改変を検知する仕組みを、AI生成コードの混入対策と同じ枠組みで整備しておくべき点が実務上の教訓となる。
